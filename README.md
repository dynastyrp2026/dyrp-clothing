# dyrp-clothing

Clothing pictures for Dynasty Roleplay.

These are the thumbnails shown in the in-game clothing shop. They are photographed in game by our own studio script and hosted here with GitHub Pages so the shop can load them.

## Files

Every picture is in the `images` folder and is named:

`<ped>_<category>_<drawable>_<colour>.webp`

- `m` = male, `f` = female
- category = the clothing slot number (for example 11 = tops, 4 = legs, 6 = shoes)
- drawable = the item number
- colour = the colour variation (0 is the first)

Example: `m_11_17_0.webp` is male, tops, item 17, first colour.

## Notes

- This repository only holds pictures. Nothing in it needs to be installed or run.
- The pictures are used by the game server only. Please do not remove or rename files, because the shop looks them up by these exact names.
